HwguiTurbo — versão 1.0.0

Integração do WebView2 (Chromium) com Hwgui/Harbour.

Stack:
• Clang 22 (MSYS2 CLANG64)
• Harbour (Git)
• Hwgui (dev)
• Microsoft WebView2 Runtime

Recursos:

  • WebView2 embutido na janela Hwgui
  • Comunicação bidirecional JS ↔ Harbour via JSON
  • Múltiplas funções Harbour expostas ao JavaScript
  • Redimensionamento automático
  • Abas arrastáveis — segure e mova para reordenar
  • Registros deletados visíveis com marcação DEL
  • Restaurar registro deletado
  • Compilação pura com Clang, sem MSVC ou GCC
